**Introduction:**
Digital Library website is an initiative, the idea is to create a platform to access knowledge digitally and fostering a love for reading. This is an initial phase of Digital Library that features a starting point to effectively provide access to a wide range of books and resources. Alongside our physical book collection, we focus to include digital content to enhance learning experience.Our mission is not only to provide easy access to books but also to create an engaging and interactive environment for learning. 

**Digital library UI**
The digital library is limited only to the School Campus. Only Computers were the target. So the ui is Static and simple interface only. 

**Digital library platform**
Digital library website is built using php, for front-end we have used html, css and javascript, for database we have used mysql.

**Features of the website**
Digital library website hosting ebooks directly in the digital library platform. All ebooks are in epub format for comfortable reading. Users can read the book with built-in reader. we have used a epub.js library for ebook reader.(http://epubjs.org/documentation/0.3/). We have used zoom in and zoom out functions to zoom and zoomout the page.
