**Introduction:**
Digital Library website is an initiative to create a platform for digital access to knowledge and foster a love for reading. This project represents the initial phase of the digital library, designed to provide easy access to a wide range of books and resources. In addition to our physical book collection, we aim to incorporate digital content to enhance the learning experience. Our mission is not only to offer convenient access to books but also to create an engaging and interactive environment for learning.

**Digital library UI**
The digital library is limited to the school campus, with computers as the primary target. As a result, the UI is static and features a simple interface. However, we are focusing on improving the UI to make it more appealing to students.

**Digital library platform**
The digital library website is built using PHP for the back-end, with HTML, CSS, and JavaScript for the front-end, and MySQL for the database.

**Features of the website**
The digital library website hosts eBooks directly on the platform, with all eBooks available in EPUB format for a comfortable reading experience. Users can read the books using the built-in reader, powered by the EPUB.js library (http://epubjs.org/documentation/0.3/). Additionally, we have implemented zoom-in and zoom-out functions to adjust the page size.
