**Introduction:**
Digital Library initiative, where we are dedicated access to knowledge and fostering a love for reading. This is an initial phase of Digital Library that features a starting point to effectively provide access to a wide range of books and resources. Alongside our physical book collection, we are also excited to include digital content to enhance learning experience.Our mission is not only to provide easy access to books but also to create an engaging and interactive environment for learning.

**Digital library platform**
Digital library website is built using php, for front-end we have used html, css and javascript, for database we have used mysql.

**Features of the website**
Digital library website hosting ebooks directly in the page.All books are in epub format for comfortable reading. Users can read the book with built-in reader. we have used a epub.js library for ebook reader. http://epubjs.org/documentation/0.3/. with zoom in and zoom out functions.
